### 🚀 Projects
* **[CliniMedi-k](https://github.com/DarkFox90/CliniMedi-k)** (Kotlin) - Offline-first Android app for managing daily patient flow in a private clinic, with separate secretary and doctor roles. Built with Jetpack Compose, MVI, and Room. My part covered the local data layer with Room and the email reminders through Resend and a Cloudflare Worker.
* **[CapaSense](https://github.com/Bini960/capasense)** (C, Python, AWS) - IoT system that controls capacity in clinic waiting rooms. An ESP32 counts people entering and leaving and controls access with a traffic light, a buzzer and a servo barrier. Data travels over MQTT through a local Mosquitto broker to AWS IoT Core, DynamoDB and CloudWatch. It is a scale-model prototype. I configured the cloud side with IAM, IoT Core, DynamoDB, and CloudWatch. [Project site](https://bini960.github.io/capasense/).
* **[Bomberman Concurrente](https://github.com/Bini960/Bomberman_Proyecto2)** (C++) - Console Bomberman that uses POSIX threads to run players, enemies, and bombs at the same time. It has a one-player mode against AI, a two-player mode, and a saved score table.
* **[Bitcoin Script Interpreter](https://github.com/Bini960/Proyecto1_BitcoinScript)** (Java) - Stack-based interpreter for a subset of Bitcoin Script that validates locking (scriptPubKey) and unlocking (scriptSig) scripts.
* **[Trees and Process Scheduling](https://github.com/Bini960/HDT8_Trees-S.O)** (Python) - Simulation that compares a Binary Search Tree, a Splay Tree, and a Red-Black Tree as the structure for scheduling processes by virtual runtime, following the idea behind the Linux Completely Fair Scheduler.
* **[RSA Cryptography](https://github.com/Bini960/Criptografia_RSA)** (Python) - App that encrypts and decrypts messages with RSA, using hand-written GCD, modular inverse, and modular exponentiation, and showing each step of the process.
* **[RickAndMortyUI](https://github.com/Bini960/RickAndMortyUI)** (Kotlin) - Jetpack Compose lab from my mobile platforms course.
